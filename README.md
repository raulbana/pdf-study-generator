# PDF Study Generator

Este projeto é uma ferramenta para gerar materiais de estudo em PDF a partir de conteúdos personalizados. Ele facilita a organização e exportação de textos, perguntas e respostas para o formato PDF, auxiliando estudantes e professores.

## Funcionalidades

- Criação de documentos de estudo personalizados
- Exportação para PDF
- Interface intuitiva para inserção de conteúdo
- Suporte a perguntas e respostas

## Instalação

1. Clone o repositório:
    ```bash
    git clone https://github.com/seu-usuario/pdf-study-generator.git
    ```
2. Instale as dependências:
    ```bash
    npm install
    ```
3. Execute o projeto:
    ```bash
    npm start
    ```

## Uso

1. Adicione o conteúdo de estudo na interface.
2. Organize perguntas e respostas conforme necessário.
3. Exporte o material para PDF.
